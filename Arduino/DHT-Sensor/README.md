# DHT Temperature and Humidity Sensor

## Overview
This project reads temperature and humidity data from a DHT sensor and outputs
the measurements through the serial interface for monitoring.

## Hardware Used
- Arduino-compatible microcontroller
- DHT temperature and humidity sensor
- Jumper wires

## How It Works
The microcontroller communicates with the DHT sensor using a digital data line,
retrieves temperature and humidity values, and prints the results at regular
intervals.

## Libraries Used
- DHT sensor library
- Adafruit Unified Sensor
